# 本地推理页面

在仓库根目录、已有 Ascend 推理环境中安装并启动：

```bash
source .venv/bin/activate
pip install -r web/requirements.txt
bash web/start.sh
```

浏览器打开 `http://127.0.0.1:19648`。Web 服务本身不加载 PyTorch 或模型；点击“加载模型”或首次提交会通过已有 `server/server-start.sh` 启动常驻 worker。

左上角只读显示工作目录，旁边的文件夹按钮打开服务器目录选择窗口，可进入子目录、返回上级或用户主目录后选择。默认 `~/.minimax-h3-310p`，选择结果记在当前浏览器，下次打开继续使用。也可通过 `--work-dir` 修改启动默认值。

```text
~/.minimax-h3-310p/
├── inputs/<任务编号>/           原始上传图片，文件名由服务生成
├── outputs/<任务编号>.mp4      最终视频
└── jobs/<任务编号>/
    ├── request.json            提示词、参数、参考图路径、状态与结果
    ├── source.mp4              超分前视频
    └── ...                     原始音视频与进度记录
```

任务记录持久化到选定目录，刷新或重启页面不影响后台任务。切换目录后显示该目录最近 100 个任务。输入图支持 PNG/JPEG/WebP，单张最多 20 MiB，多参考图最多 8 张。页面支持文字、首尾帧、多参考图三种互斥模式；Dasiwa Hybrid 复用同一主干，但多参考 + TaoMate 三步的质量仍需分别验证。

默认仅监听本机。需要在另一台电脑浏览时，可使用 SSH 端口转发，例如 `ssh -L 19648:127.0.0.1:19648 user@server`。`--host`、`--port`、`--device` 可调整监听地址、端口和主生成设备。这是可信本地环境使用的页面，没有多用户权限隔离。

```bash
bash web/start.sh --port 19648 --device 1 --work-dir ~/.minimax-h3-310p
python -m unittest discover -s web/tests -v
```

页面显示的 720P/1080P 是 512 级生成后超分。按 24 fps、17k+5 帧规则显示实际时长；时长输入上限 60 秒只是页面校验范围，不表示显存保证支持该时长。停止 Web 进程不会卸载常驻模型；如需释放 NPU，运行 `bash server/server-start.sh --stop`。

## 创作工作台与文件树

页面采用暖色工作台布局：左侧上方为工作目录文件树，下方为生成参数，中间用分隔线区分；右侧为视频预览和底部输入框。文件区和参数区可独立收起，并记住显示状态。参考图在输入框上方显示，可逐张移除，也支持拖入图片；Ctrl / Command + Enter 提交。

文件树可展开目录，上传文件、下载、重命名和永久删除。点击图片或视频可预览，右键菜单提供下载、重命名、删除，图片还可用作参考图（也支持 Shift + F10 打开菜单）；上传目标为选中的文件夹，选中文件时为其父目录，未选中则为输入目录。已有同名文件不会覆盖。删除前需要确认，目录删除包含其全部内容。生成过程中暂不允许重命名和删除，以免影响正在执行的任务。基础 inputs / outputs / jobs 文件夹不能重命名或删除；符号链接不在文件树中显示，也不能操作。

文件树按需加载目录，已展开目录复用缓存，点击文件不会重新请求目录列表。上传、重命名、删除后自动更新，外部修改文件后可点击文件栏刷新按钮同步。

文件树顶层仅展示“输入 / 任务 / 输出”，磁盘目录名仍为 inputs / jobs / outputs。三个基础目录不能重命名或删除。任务项目与关联的输入、输出、任务内部文件受保护，不能单独删除或重命名。

右键任务项目选择“删除项目”后，弹出二次确认框；默认只删除项目记录和中间文件，可勾选同时清理关联输入、输出。其它项目仍在使用的文件保留；仅清理变为空的输入子目录，不删除其中无关联的文件。排队或运行中的项目不能删除。文件接口和任务记录操作在 Web 进程内串行执行，避免页面轮询与删除同时修改记录。

生成记录统一展示在“任务”目录，默认展开。项目、关联素材目录和输出视频采用提示词摘要与创建时间作为显示名称，内部磁盘路径仍保持稳定的任务编号。点击任务可查看结果与进度；上传、刷新、文件类型和展开箭头采用统一的细线 SVG 图标。

文件区和参数区收起后保留可点击的展开条；同时收起时，桌面保留窄侧栏，手机保留水平展开条。预览区直接展示视频，不再显示装饰标题、复用参数和独立下载按钮；下载仍可通过文件树右键菜单完成。

侧栏整体可横向收起，保留窄展开条；文件区和参数区各自纵向折叠。随机种子直接显示在参数区，固定种子默认不勾选；任务成功提交后，未固定的种子自动加 1，提交失败不递增。种子达到允许的上限时递增回到 0。
